# Surge 自动接工单与锁屏通知模块

本模块用于在无需打开电脑、无需打开企业微信的情况下，全自动在后台抢接供热系统工单并向 iPhone 发送锁屏通知。

## 功能特性

1. **全自动抢单**：每天北京时间 08:00–16:00 期间，每 1 分钟检测一次“待抢工单（未接单）”，发现新工单即刻发送 POST 请求完成接单。
2. **全类型支持**：覆盖维修、开停栓、营业、稽查等所有类型工单。
3. **防重接单**：自动记录当天已接单列表，避免重复发起请求。
4. **锁屏通知**：成功接单后，自动向 iPhone 发送本地系统横幅通知，展示工单类型、单号、任务地址与派单时间。
5. **静默唤醒**：配置 `wake-system=true`，iPhone 锁屏息屏也能按时静默唤醒执行。
6. **时效守卫**：每天 08:00–16:00 执行抢单，其余时间（如夜间手动测试）只做连通性检测；有效期限至 2027-12-31。

## iPhone 安装与更新方法

1. 打开 **Surge iOS**。
2. 进入 **“模块 (Modules)”**。
3. 如果已有旧的“工单自动接取”模块，点击它并选择 **“更新 (Update)”** 即可拉取最新脚本；若未安装，点击 **“安装新模块”** 并输入地址：
   ```text
   https://raw.githubusercontent.com/eielyving/surge-workorder-monitor/main/workorder-monitor.sgmodule
   ```
4. 启用模块后，可在 Surge 脚本列表中点击该任务并选择“立即执行”，查看日志确认网络连通性。
