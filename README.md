# Surge 自动接工单与通知模块 (增强版)

本模块用于在无需打开电脑、无需打开企业微信的情况下，全自动在后台接取供热系统工单并向 iPhone 发送系统通知。

## 功能特性

1. **全自动接单**：每天北京时间 08:00–16:00 期间，每 6 分钟检测一次“待接工单（未接单）”，发现新工单即刻发送 POST 请求完成接单。
2. **全类型支持**：覆盖维修、开停栓、营业、稽查等所有类型工单。
3. **隐私脱敏**：脚本源码无任何硬编码个人隐私，通过 Surge 原生 `#!arguments` 参数化配置。
4. **防漏单异常告警**：严格区分“正常无单”与“系统页面异常/改版”，一旦页面结构不匹配或服务不可用，立即触发系统异常通知。
5. **逐单即时去重**：每成功接取一张工单，立即写入本地持久化存储，防止后续超时导致记录丢失重复接单。
6. **业务响应校验**：不仅检查 HTTP 状态码，还严格校验后端业务返回内容，拦截业务失败。
7. **静默唤醒与通知**：配置 `wake-system=true` 保证息屏后台唤醒；成功接单后发送 iOS 系统横幅通知。

## 安装与配置方法

### 1. 安装模块
在 Surge iOS 中进入 **“模块 (Modules)”** -> **“安装新模块”**，输入地址：
```text
https://raw.githubusercontent.com/eielyving/surge-workorder-monitor/main/workorder-monitor.sgmodule
```

### 2. 填写参数
安装或启用模块时，Surge 会弹出参数输入框，请依次填入：
* **loginid**：你的登录手机号（如 `18643724008`）
* **userid**：系统分配的用户ID（如 `2687`）
* **username**：员工姓名（如 `王信答`）

*注：这些身份信息保存在你手机本地，不会上传至公开仓库。*

### 3. 查看运行与测试
* 模块启用后，将在每天 08:00–16:00 静默运行。
* 非工作时段手动执行时，脚本会自动执行网络与系统连通性自测，并在日志中输出当前系统状态。
