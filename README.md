# Surge 自动接工单与通知模块

本模块用于在无需打开电脑、无需打开企业微信的情况下，全自动在后台接取供热系统工单并向 iPhone 发送系统通知。

## 功能特性

1. **全自动接单**：每天北京时间 08:00–16:00 期间，每 8 分钟检测一次“待接工单（未接单）”，发现新工单即刻发送 POST 请求完成接单。
2. **全类型支持**：覆盖维修、开停栓、营业、稽查等所有类型工单。
3. **隐私脱敏配置**：公共仓库无任何个人身份信息，通过 Surge 模块参数传入，仅保存在用户设备配置中。
4. **FIFO 严格时间优先排序**：
   - 采用多格式安全时间戳解析器（精确支持标准日期时间及 14 位单号时间戳），严格按派单时间先后升序排列；
   - 即使发生短暂工单累积，最早派出的工单永远优先接单，彻底消除旧单被新单反复插队延后的风险。
5. **待确认状态自愈与恢复补发通知**：
   - 当遇到网络偶发中断或页面截断导致无法即时确认工单状态时，将工单安全暂存入本地待确认队列并发送提示；
   - 在后续轮询恢复连接后，一旦核验工单已成功进入服务端“处理中”，**自动补发【自动接单恢复确认成功】锁屏通知**，实现状态机最终一致闭环。
6. **双向网络自愈重试与防超时安全窗口**：
   - **双向 1 秒延迟重试**：列表读取与状态复核两道防线均具备失败自动重试机制；
   - **请求超时与总时限匹配**：单请求超时优化为 5 秒，极端全失败最坏耗时仅约 43 秒，远低于模块配置的 75 秒总时限，杜绝脚本被系统强制终止。
7. **防御性去重与防崩溃保护**：
   - 内存批次 Set + 本地持久化双重过滤，并在 POST 发出前进行最后拦截，彻底防止重复工单提交；
   - 本地持久化记录增加非空与类型防御，彻底杜绝 JSON 解析异常导致的脚本中断。
8. **静默唤醒与通知**：配置 `wake-system=true` 保证息屏后台唤醒；每小时 7~8 次运行，不触发 Surge 高频耗电警告；成功接单后发送包含工单类型、单号、地址与派单时间的 iOS 系统横幅通知。

> [!WARNING]
> 本供热客服系统使用的是 HTTP 明文传输，请求中包含工单信息与身份标识。请确保在受信任的网络环境中使用。

## 适用场景与时效说明

* **常规到单场景（推荐）**：供热系统工单通常分散到达（单次 1~2 张），在 8 分钟主频与每轮 2 张限额下，新工单均能在 20 分钟窗口内极速接取。
* **突发大批量场景**：若遇极端管网事故或短时集中涌入 5 张以上工单，前 4 张将在 16 分钟内接取完毕，其余工单将严格按 FIFO 派单时间先后在后续周期顺延处理。

## 安装与配置方法

### 1. 安装模块
在 Surge iOS 中进入 **“模块 (Modules)”** -> **“安装新模块”**，输入地址：
```text
https://raw.githubusercontent.com/eielyving/surge-workorder-monitor/main/workorder-monitor.sgmodule
```

### 2. 填写参数
安装或启用模块时，请填入你的实际业务身份信息（示例使用虚拟占位）：
* **loginid**：你的登录手机号（示例：`13800000000`）
* **userid**：系统分配的用户ID（示例：`1001`）
* **username**：员工姓名（示例：`张三`）

*如果你的 Surge iOS 版本不支持图形弹窗输入，也可以在模块列表中点击该模块选择“编辑内容”，在 `argument` 字段中直接填入对应的值。*

### 3. 查看运行与测试
* 模块启用后，将在每天 08:00–16:00 静默运行。
* 非工作时段手动执行时，脚本会自动执行网络与系统连通性自测，并在控制台日志中输出当前系统状态。
